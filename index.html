1. Types of Motors Used in Robots

⚙️

DC Geared Motor

Mobile Robots / AGV

Converts DC electrical energy into rotary mechanical motion. A gearbox reduces speed and increases output torque.

  • Voltage: 6–48 V
  • Power: 5–500 W
  • Output speed: 10–1000 RPM
  • Feedback: Encoder optional
  • Control: PWM / H-bridge
🔄

BLDC Motor

Drones / Humanoids

Uses electronic commutation instead of mechanical brushes. Offers high efficiency and power density.

  • Voltage: 12–60 V (small robots)
  • Power: 50 W–5 kW+
  • Speed: 500–10000+ RPM
  • Feedback: Hall / Encoder
  • Control: ESC / FOC
🎯

Servo Motor

Industrial Robotic Arms

Uses feedback to accurately control position, speed and torque.

  • Supply: 24–48 V DC or AC drive systems
  • Power: 50 W–5 kW+
  • Speed: 1000–6000 RPM
  • Feedback: Encoder / Resolver
  • Control: Closed-loop PID
🔩

Stepper Motor

Positioning Systems

Rotates in discrete angular steps based on input pulses.

  • Driver voltage: 12–48 V typical
  • Step angle: 1.8° / 0.9°
  • Holding torque: 0.1–3 Nm
  • Feedback: Optional encoder
  • Control: Pulse / Direction
↕️

Linear Actuator

Lifting / Grippers

Produces linear motion using a lead screw, belt or electromagnetic mechanism.

  • Supply: 12–48 V typical
  • Force: 100–10000 N
  • Stroke: 50–1000 mm
  • Speed: 5–100 mm/s
  • Feedback: Limit switch / Encoder
⭕

Direct-Drive Torque Motor

Humanoid Joints

Produces high torque at low speed without requiring a conventional gearbox.

  • Supply: Drive-dependent
  • Power: 50 W–several kW
  • Speed: 10–1000 RPM typical
  • Feedback: High-resolution encoder
  • Control: Servo / FOC

4. Motor Working Principle – Animated Demonstration

Rotating Motor Shaft

Electrical input → Magnetic field → Electromagnetic torque → Shaft rotation

DC motor: T ∝ Ia
Back EMF: Eb = Ke × ω
Mechanical Power: P = T × ω

Control Methods

DC Motor – PWM

Duty cycle determines average motor voltage.

Vavg = D × Vs

BLDC – Electronic Commutation

Electronic switching energizes stator phases according to rotor position.

FOC: Id / Iq current control

Stepper – Pulse Control

Number of pulses determines angular displacement.

θ = Np × θstep

Servo – Feedback Control

Position error is used by the controller to generate corrective action.

e(t) = θref − θactual

7. Motor Drivers and Feedback Sensors

Motor Drivers

  • DC: BTS7960 / H-bridge
  • BLDC: ESC / FOC controller
  • Stepper: A4988 / DRV8825 / DM542
  • Servo: Manufacturer-specific drive
  • Linear: H-bridge / actuator drive

Feedback Sensors

  • Incremental encoder
  • Absolute encoder
  • Hall effect sensor
  • Resolver
  • Limit switch
  • Current and temperature sensors

Control System

Reference input → Controller → Motor driver → Motor → Mechanical load

Encoder / Hall feedback → Controller

Closed-loop control:
e(t) = Reference − Feedback
